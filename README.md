

# Secupay PlentyONE
This repository contains the PlentyONE extension that enables to process payments with [Secupay](https://secupay.com//).

###### To use this extension, a [Secupay](https://secupay.com//) account is required.

## Requirements

* [PlentyONE 7](https://www.plentyone.com/)
* [IO](https://marketplace.plentyone.com/plugins/channels/online-shops/io_4696)
* [Ceres](https://marketplace.plentyone.com/plugins/channels/online-shops/ceres_4697)
